# To-Do List Application
## Project Description
The To-Do List Application is a simple command-line Python program that helps users organize and manage their daily tasks. Users can add tasks, view all tasks, delete tasks, and mark tasks as completed. Task data is stored permanently using a JSON file, so it is available even after restarting the application.
## Features
- Add new tasks
- View all tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using JSON
- Load saved tasks automatically
 🛠 Technologies Used
- Python 3
- JSON
- File Handling

## How to Run
1. Open Terminal or Command Prompt.
2. Navigate to the project folder.
```bash
cd ToDo_List
```
3. Run the program.
```bash
python todo_list.py
```
